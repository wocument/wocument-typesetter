# editorial-foundations

Shared knowledge for the editorial skills. Not a command: it makes no decisions and writes no
output. Every editorial skill reads it through `${CLAUDE_PLUGIN_ROOT}/skills/editorial-foundations/references/`.

| File | Holds |
|---|---|
| `references/mechanics.md` | 25 approved rules that hold across publications, grouped by the skill that owns each decision |
| `references/profiles.md` | 18 aesthetic profiles, ordered by expressiveness: the first theme-catalogue entries |
| `references/print-to-web.md` | How each mechanic behaves on phone, tablet and wide screens |
| `references/engine-wishlist.md` | What the rules ask for that the engine cannot do yet, with workarounds |

Everything here is written in our own words from a private study of reference publications.
The study material and its evidence stay outside the repository.
