# Print to web: each mechanic per breakpoint

The sources are print spreads; Wocument pages are read on phones, tablets and wide screens.
The goal is the same feel on every screen, not the same layout. Phone is about 390 px,
tablet about 768 px, wide 1280 px and up. "Spread" on a screen means one scene.

| Mechanic | Wide | Tablet | Phone |
|---|---|---|---|
| C1 expressiveness | As the profile | As the profile | Keep the type voice and colour; drop most grid breaks and overlaps first |
| M2 breaks between units | Scene order | Same | Same |
| M5 front matter differs | Own palette or grid | Same | Palette carries it alone |
| T1 type paces text | Pull quotes across 2 columns, large drop caps | Pull quotes across the measure | Pull quote full width between paragraphs; drop cap 3 lines at most |
| T2 package kit | Full kit | Full kit | Label, colour and display type; ornaments may drop |
| T7 + C4 one grid break | Cut-out across a column or edge | Fewer overlaps | Cut-out inside the column, no overlap; captions directly under |
| F1 spread pacing | Text scene, then picture scene | Same | Same order; a picture reset is one full-width picture |
| F2 quote on a photo | Quote in the quiet area; may split across the fold | Quote in the quiet area, not split | Quote above or below the picture, not on it |
| B1 density | Profile setting | Same | One column; paragraph space may return for readability |
| M3 one lead bleed | One picture bleeds | Same | Lead picture full width; the rest at column width |
| F3 quiet zone | `focus` keeps it in frame | Same | Same; check the crop still leaves room, or move the type off the picture |
| M1 templates | Same snippet | Same | Same snippet, its phone values |
| M4 captions second voice | Gathered block on picture-led spreads | Gathered or under each picture | Always under each picture; position words like "opposite" are not used |
| T6 author line at the end | In the alley or after the text | After the text | After the text |
| B2 alley | Narrow frame in the alley | Alley may close | Content inline, after the paragraph it belongs to |
| B4 repeated shape | Folio, bullets, end mark | Same | Same |
| C2 polished copyfitting | Justified, hyphenated, indented | Justified if the measure is at least about 45 characters | Ragged right, hyphenated |
| C5 label slug | Slug | Slug | Slug |
| T3 series | One template, varied colour | Same | Same |
| T4 data page | Grid of numbers or charts | 2 per row | 1 per row; charts must read at 390 px |
| B5 portrait grids | 4–6 per row, or alternating sides | 3 per row | 2 per row; alternating becomes stacked |
| B6 + C6 points and Q&A | Columns | Columns | One column; numbers and questions keep the second voice |
| F4 roundup islands | Islands scattered on the grid | Fewer per row | One per row, picture then text; numbers kept |
| F5 mixed-size headline | Line by line | Same | Check every line still fits; reduce the size ratio rather than break words |
