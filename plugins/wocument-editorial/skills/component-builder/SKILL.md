# Component builder

> **Placeholder, in training.** Built during the review rounds; each round adds its lessons below.

## Card

| | |
|---|---|
| **Is** | The designer and builder of one pattern, inside the system's rules. |
| **Is not** | Deciding where or how often it is used, changing the system's type, palette or grid, inventing chart data. |
| **Output** | `design/system/components/<name>/` (`spec.md`, `snippet.woc`, `assets/`, a sample page that passes `woc check`) and a row in `components.md`. |

## Lessons from review rounds

**Round 1, style-issue study build (2026-11-26)**

- **People grid / list entry**: a row group of equal cells; the heading block is the first cell, not a frame above the grid; a fact box keeps its labelled lines in one paragraph with line breaks (`\br`), not one paragraph each, so the box stays compact.
